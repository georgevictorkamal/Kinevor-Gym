# Getting help

| I want to... | Go to |
| --- | --- |
| Report a bug | [Open a bug report](https://github.com/georgevictorkamal/Kinevor-Gym/issues/new?template=bug.yml) |
| Suggest a feature | [Open a feature request](https://github.com/georgevictorkamal/Kinevor-Gym/issues/new?template=feature.yml) |
| Ask how something works | [Discussions](https://github.com/georgevictorkamal/Kinevor-Gym/discussions) (Q&A) |
| Report a security problem | Follow [SECURITY.md](SECURITY.md) and use private reporting, not a public issue |
| Contribute code or docs | Read [CONTRIBUTING.md](CONTRIBUTING.md) and pick a [good first issue](https://github.com/georgevictorkamal/Kinevor-Gym/labels/good%20first%20issue) |

Before opening an issue, please run `node scripts/verify-repo.mjs` and check the
[deployment guide](docs/deployment.md) for port and environment questions.
